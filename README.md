# arunoruto/homebrew-tap

Homebrew formulae for my projects, on macOS and Linux:

```sh
brew tap arunoruto/tap
brew install <formula>        # or in one go: brew install arunoruto/tap/<formula>
```

| Formula | What it is |
|---|---|
| [carrel](https://github.com/arunoruto/carrel) | A research paper library for you and your AI ([full setup](https://arunoruto.github.io/carrel/docs/setup/)) |

Formulae are written by each project's release workflow, which pushes with a deploy key of its own; edits made here directly are overwritten by the next release.
